# SkillOS

**An Operating System for AI Agents**

SkillOS is an AI orchestration framework that enables agents to dynamically create reusable skills, plan multi-step workflows, validate generated capabilities, and execute business tasks through isolated runtime modules. Rather than relying solely on predefined tools, SkillOS allows its capability library to expand over time while maintaining structured execution and human oversight.

## Overview

Current AI agents often depend on fixed tools and capabilities. When users request unsupported functionality, additional development is typically required before execution can continue.

SkillOS addresses this limitation by treating capabilities as reusable **skills**. A Planning Module decomposes user requests into workflow steps, determines whether existing skills can satisfy each task, and invokes the Skill Factory whenever a new capability is required. Newly generated skills are evaluated, reviewed, registered, and become reusable components for future workflows.

The project was developed as a submission for the **AI Agents: Intensive Vibe Coding Capstone Project** under the **Agent for Business** track.

```
                                      │

```

## Execution Workflow

Example request:

> *"Write a report on the given financial data, summarize it, and translate the summary into Spanish."*

Execution plan:

1. Report Generation
2. Report Summarization
3. Translation

Each workflow step can use outputs generated by previous steps.

## Quick Start

- Kaggle notebook: https://www.kaggle.com/code/hserdaraltan/skillos-a-business-startup-use-case
- GitHub repo: https://github.com/hsaltan/Machine-Learning/tree/main/SkillOS/notebook
- YouTube video: https://youtu.be/0nMIZEJK7B4

### Run a SkillOS Scenario

1. Open the Kaggle notebook.
2. Select a demonstration scenario from the **Scenario** dropdown menu.
3. Click **✓ Submit**.
4. Run the above cell to begin execution.
5. Review the generated workflow output displayed in the notebook.

### Publish a Generated Website to GitHub

1. Enter the GitHub repository name.
2. Click **📦 Create Repository**.
3. Run the following cell to create a new public repository or update an existing one.
4. Optionally enter a commit message (defaults to **"Add web page"** if left empty).
5. Click **🚀 Publish Website**.
6. Run the following cell to collect all generated web files from the project's web directory and publish them to the specified GitHub repository through the GitHub MCP workflow.
7. Review the GitHub MCP execution result displayed in the notebook.

## MCP Integration

SkillOS currently integrates with GitHub through the **Model Context Protocol (MCP)**, supporting repository creation, file updates, and website publishing. The architecture can be extended to additional MCP providers.

## Limitations

Current limitations include dependence on foundation models, sequential workflow execution, a limited runtime library, reliance on external API availability, and a YAML-based skill registry.
